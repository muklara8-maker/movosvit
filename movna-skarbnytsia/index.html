Методична скарбниця

Бібліотека матеріалів до уроків: робочі аркуші, дидактичні картки, тести, інтерактивні вправи, презентації та методичні рекомендації. Обирайте клас, шукайте матеріали й доповнюйте власну колекцію.

Матеріали до уроків

Оберіть клас або перегляньте всі матеріали. Опубліковані розробки доступні всім, особисті — лише в цьому браузері.

Додати власну розробку

Додайте файл або посилання. Матеріал збережеться локально в браузері цього пристрою. Для публікації на сайті скористайтеся інструкцією нижче.

Резервна копія особистої бібліотеки

Щоб перенести матеріали на інший комп’ютер або не втратити їх під час очищення браузера, збережіть резервну копію. Вона містить також вкладені файли.

Для великих файлів браузер може мати обмеження на обсяг збереження. Не використовуйте особисту бібліотеку як єдине місце зберігання розробок.

Методичні рекомендації

1. Підготовка уроку

Оберіть клас і тему, доберіть матеріал відповідно до мети та очікуваних результатів уроку.

2. Робота з картками

Використовуйте картки для індивідуальної, парної та групової роботи, передбачайте взаємоперевірку.

3. Перевірка знань

Додавайте до тестів ключі й критерії оцінювання, обговорюйте типові помилки.

4. Інтерактивні вправи

Поєднуйте цифрові ігри з письмовими завданнями та рефлексією.

5. Матеріали для друку

Для друку зручно використовувати PDF; Word-файли можна попередньо редагувати.

6. Авторські розробки

Указуйте назву, клас, тему й коротку інструкцію. Перевіряйте матеріали перед публікацією.

Як опублікувати матеріал для всіх відвідувачів

Особисте додавання не публікує файли на GitHub. Щоб розробка стала загальнодоступною, завантажте її до папки movna-skarbnytsia/materials/ у репозиторії, а опис додайте до файлу movna-skarbnytsia/materials.json. Приклад запису наведено в README архіву.

Папку сторінки залишено з технічною назвою movna-skarbnytsia, щоб не порушити чинні посилання. Видима назва скрізь — «Методична скарбниця».
